# Nintendo 64 games

Place legally obtained Nintendo 64 homebrew or cartridge images here.
Pixel64 recognizes big-endian `.z64`, byte-swapped `.v64`, and little-endian
`.n64` images and normalizes them internally without changing the source file.

Pixel64 is an early development core. Its first compatibility target is Super
Mario 64 (USA) revision 0. A cartridge appearing in the dashboard is not yet a
claim of completed gameplay compatibility.
